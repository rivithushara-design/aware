# Contributing to Aware

Thanks for helping out. Aware is early, so small contributions matter a lot.

## Ways to contribute

- **Add a bank parser.** This is the most useful contribution. See [docs/adding-a-bank.md](docs/adding-a-bank.md).
- Report bugs or request a bank using the issue templates.
- Improve docs.
- Fix issues labeled `good first issue`.

## Ground rules

1. **Privacy first.** Never commit or post real SMS messages. Redact account numbers, names, phone numbers and balances. Use fake but realistic values.
2. **No secrets.** Do not commit API keys, tokens or `.env` files.
3. **Read-only.** Features that move money will not be accepted.
4. Be kind. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Workflow

1. Fork the repo and create a branch: `git checkout -b add-bank-xyz`
2. Make your change. Keep pull requests small and focused.
3. Add or update tests for any parser you touch.
4. Open a pull request and fill in the template.

## Commit style

Short, imperative messages, for example `Add Commercial Bank SMS parser`.

## Questions

Open a GitHub Discussion or an issue.
