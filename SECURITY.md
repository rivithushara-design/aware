# Security Policy

Aware handles financial data, so we take security and privacy seriously.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Email rivithushara@gmail.com with:

- A description of the issue
- Steps to reproduce
- The impact you think it has

You can expect an acknowledgement within a few days.

## Design commitments

- SMS content is parsed on-device and is not uploaded.
- Aware is read-only and never initiates payments or transfers.
- No credentials for banks are ever requested or stored.

## Supported versions

Only the latest `main` branch is supported while the project is in early development.
